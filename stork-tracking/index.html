Where do white storks stop on the way south?

A small data pipeline that turns 7.2 million raw GPS fixes from 60 white storks into ordered movement sequences, analyzes them with SQL window functions, finds multi-day stopovers, and lets anyone ask questions in plain English, with an LLM writing the SQL.

Data

From 7.2 million fixes to clean sequences

The data comes from the Movebank Data Repository: Fall migration of white storks in 2014 (Flack, Fiedler, Wikelski), doi:10.5441/001/1.bj96m274. Sixty storks were tagged in southern Germany and tracked from 1 August to 1 October 2014.

Why one fix per 5 minutes?

The tags record a fix every 5 to 15 minutes, plus 1-second bursts that make up 93.6% of all rows. With mixed step sizes, 99.4% of points looked like stops and the top speed came out at 64,768 km/h. Keeping the first fix in each 5-minute window brings the 99th-percentile speed down to 47 km/h, which is realistic for a stork.

The LAG window function

The SQL version matches the pandas version: 0 mismatches across all 421,898 rows.

WITH lagged AS (
  SELECT animal_id, timestamp, latitude,
         LAG(latitude) OVER (
           PARTITION BY animal_id
           ORDER BY timestamp) AS prev_lat
  FROM tracking
)
SELECT *, latitude - prev_lat AS lat_change
FROM lagged;

Lesson learned

WHERE runs before window functions. My first version filtered first, so the first row had no previous row. The fix is to compute the window function in a CTE first and filter afterwards.

Stopovers use the gaps-and-islands trick: consecutive rest days share the same value of julianday(day) - ROW_NUMBER(), so grouping by it finds each multi-day stop.

Findings

Everyone went west, five crossed the Sahara

  • Ekky flew the farthest: 7,956 km in 62 days (about 129 km per day), reaching the Sahel near the Mali and Niger border. The top 5 by distance are exactly the 5 storks that crossed the Sahara.
  • Everyone took the western route: Germany, France, Spain, then the Strait of Gibraltar. By 1 October: Sahel 5, Morocco 9, near Gibraltar 7, Spain or southern France 32, and 7 barely left Germany.
  • Biggest single day: Schwitza flew 558 km on 14 September 2014.
  • Stopovers: Blacky and Chompy each waited about 8 days near the Strait of Gibraltar.
  • Data gaps matter: 28 of 60 tracks end early. One tag was silent for 5 days and then reported a single 1,097 km step. Some long "rests" end on the day a track ends, which more likely means the bird died or lost its tag.

Ask the data

An LLM writes the SQL, safely

ask_data.py lets a non-technical user type a question such as "Which stork flew the farthest?". Claude gets the table schema, what each column means, the data-quality rules found above, and three example question and SQL pairs.

Safety layers

  • Only a single SELECT or WITH statement, with no data-changing keywords.
  • LIMIT 200 is added to every query.
  • Runs on a read-only connection, so even a missed write is refused by SQLite.
  • If the SQL fails, the error goes back to the model once for a fix.
  • The generated SQL is always shown, so the user can check it.

Status and limits

The safety layer is tested: DROP, a DELETE hidden inside WITH, stacked statements and ATTACH are all blocked. The LLM calls themselves have not been run yet, because they need an API key.

An LLM can write SQL that runs but answers a slightly different question. That is why the SQL is always shown and why the prompt spells out the data rules.
